Claude CLI installation
Prerequisites:
a) User must be part of Group- ClaudeAiMachines
b) Node Js should be installed
1) Open the command prompt as normal user and run the below command: npm install -g @anthropic-ai/claude-code
2) Once the claude is installed add the path to the environment variables
under the edit environment variables for your account
C:\Users\YourUsername\AppData\Roaming\npm\
3) Once set successfully try claude –version in cmd/PowerShell/VS code terminal
